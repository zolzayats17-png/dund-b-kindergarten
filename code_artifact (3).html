Supabase & Vercel Байршуулах Иж Бүрэн Заавар

Нийслэлийн хүүхдийн 33 дугаар цэцэрлэгийн Дунд Б бүлгийн системийг бодит датабаазтай холбож, онлайнд 100% үнэгүй байршуулан эцэг эхчүүдэд холбоосоор түгээх алхамчилсан гарын авлага.

1

GitHub дээр Код Бэлдэх

  • GitHub.com рүү ороод шинэ Repository (жишээ нь: dund-b-kindergarten) үүсгэнэ.
  • Энэхүү index.html файлыг сан руугаа git push хийж эсвэл шууд Upload хийж хадгална.
2

Supabase Датабааз Үүсгэх

  • Supabase.com сайт дээр үнэгүй бүртгүүлж "New Project" дарна.
  • Төслийн нэрээ 33-kindergarten-dund-b гэж өгөөд Нууц үг зохион үүсгэнэ.
  • Зүүн цэсний SQL Editor хэсэг рүү орно.
3

Supabase SQL Скрипт Ажиллуулах

Доорх SQL кодыг хуулж аваад Supabase SQL Editor дээр Run хийж хүснэгтүүдийг үүсгэнэ.

-- 1. Хүүхдүүдийн хүснэгт
CREATE TABLE children (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    last_name TEXT NOT NULL,
    first_name TEXT NOT NULL,
    age INT NOT NULL,
    gender TEXT NOT NULL,
    reg_number TEXT UNIQUE NOT NULL,
    parent_name TEXT NOT NULL,
    parent_phone TEXT NOT NULL,
    note TEXT,
    photo_url TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Өдөр тутмын ажиглалтын хүснэгт
CREATE TABLE daily_observations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    child_id UUID REFERENCES children(id) ON DELETE CASCADE,
    subject TEXT NOT NULL,
    content TEXT NOT NULL,
    media_url TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 3. Ярилцлагын тэмдэглэлийн хүснэгт
CREATE TABLE interview_notes (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    question TEXT NOT NULL,
    response TEXT NOT NULL,
    media_url TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 4. Мэдээ мэдээллийн хүснэгт
CREATE TABLE news_feed (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    title TEXT NOT NULL,
    category TEXT NOT NULL,
    content TEXT NOT NULL,
    image_url TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 5. Эцэг эхийн санал хүсэлтийн хүснэгт
CREATE TABLE parent_feedbacks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    sender TEXT NOT NULL,
    type TEXT NOT NULL,
    content TEXT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
4

Vercel дээр Байршуулах

  • Vercel.com руу GitHub хаягаараа нэвтрэн орно.
  • "Add New Project" сонгоод 1-р алхамд үүсгэсэн GitHub репозиторигоо импортолж оруулна.
  • Deploy товчийг дарснаар 1-2 минутын дотор систем интернетэд бэлэн болно.
5

Эцэг Эхчүүдэд Түгээх

Vercel-ээс гаргаж өгсөн бэлэн холбоосыг (жишээ нь: https://33-dund-b.vercel.app) авч ангийн чат эсвэл фэйсбүүк группийн эцэг эхчүүдэд илгээнэ.

Эцэг эхчүүд шууд мэдээлэл үзэх ба санал илгээх бөгөөд багш нууц үгээрээ нэвтэрч удирдна.
